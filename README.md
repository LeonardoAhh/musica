# Se Sufre Bonito 🎶

Plataforma editorial para descubrir joyas musicales: salsa romántica, salsa brava, cumbia y música que se baila y se siente.

## Estado

Repositorio conectado con ChatGPT. **Pendiente:** importar el código fuente de la primera edición Next.js, validar `npm run build` y realizar el despliegue a Vercel. Este README no significa que la aplicación ya esté publicada.

## Diseño

Interfaz editorial responsive para móvil, tablet y escritorio. Canvas off-white, tipografía elegante, botones discretos y acentos atmosféricos suaves. Se mantiene un `DESIGN.md` dentro del paquete del proyecto inicial.

## Siguiente paso

1. Incorporar los archivos del paquete `se-sufre-bonito-edicion-01.zip` **descomprimiéndolo primero**: subir el contenido de la carpeta interna `se-sufre-bonito/` a la raíz del repositorio (no el ZIP como único archivo).
2. Ejecutar `npm install`, `npm run lint` y `npm run build`; corregir cualquier fallo.
3. En Vercel: **Add New → Project → Import Git Repository → LeonardoAhh/musica**; revisar el framework Next.js y pulsar **Deploy**.

El proyecto está en fase inicial y seguirá evolucionando con la colección musical y las valoraciones recopiladas.
